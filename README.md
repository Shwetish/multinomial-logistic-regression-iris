# multinomial-logistic-regression-iris
A complete, beginner-friendly Python tutorial implementing multinomial logistic regression using scikit-learn on both the Iris and Wine benchmark datasets, complete with step-by-step performance metrics and detailed metric explanations.

# Multiclass Classification with Multinomial Logistic Regression

This project contains clean, well-commented Python code demonstrating how to build, evaluate, and interpret **Multinomial Logistic Regression** models using `scikit-learn`. It walks through two popular datasets:
1. **Iris Dataset**: A classic, highly separable dataset predicting flower species based on physical dimensions.
2. **Wine Dataset**: A multi-class chemical feature dataset predicting wine cultivars, complete with deep metric analysis (Precision, Recall, F1-Score, and Support).

## Features
* End-to-end machine learning pipeline (`load_data` -> `train_test_split` -> `fit` -> `predict` -> `evaluate`).
* Clear analogies linking abstract ML concepts to real-world scenarios (e.g., student study hours, wine characteristics).
* Manual class-wise accuracy loops.
* Detailed inline breakdowns of classification reports and optimization parameters (`solver='lbfgs'`).

## Requirements
* Python 3.x
* NumPy
* Pandas
* scikit-learn

## Usage
Run the script to train models and output evaluation metrics for both datasets.
